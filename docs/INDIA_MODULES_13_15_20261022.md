## Kontrol penting

- Tidak ada seed bisnis, akun produksi atau API key di migrasi.
- Endpoint memakai autentikasi/role Cloudflare Access dan membership existing; fixture hanya untuk pengujian.
- Mutasi purchase, cost, settings, number, catalog, member dan report memakai D1 batch atomik termasuk audit; kegagalan audit membatalkan transaksi.
- Purchase approve/order memeriksa ulang harga/version/status/expiry supplier serta kapasitas kumulatif. Harga browser tidak dipercaya.
- Perjanjian/lisensi memerlukan encrypted original Vault yang terikat Opportunity, bukan metadata arsip saja.
- Sales tidak memperoleh HPP, actual costs, purchase/evaluation ledger atau customer profitability. Owner filtering diterapkan server-side dan saved report tidak mengubah izin data.
- Settings efektif adalah versi approved tertinggi; draft/rejected tidak berlaku. API integration registry tidak melakukan request HTTP ke endpoint pengguna.
- Organisasi dan assigned unit adalah metadata manajemen; tidak mengklaim multi-institusi atau pembatasan data per-unit baru.
